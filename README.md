# 戦略メーカー `Ver.1`

週末のコンサルの組み立て(作戦表)を、上長の頭の中から取り出して部下に見せる無料ツールです。

**公開URL:** https://hissernoob.github.io/sennryakumaker/

---

## 1. このツールでできること

毎週の作戦(どの機種で注意を引き、どの機種に着地させ、どう話すか)を1枚のシートにまとめ、**作成 → プレビュー → PDF出力** の流れで部下に共有します。現在はテレビ(43型)の作戦づくりを想定しています。

| 機能 | 内容 |
|---|---|
| 作戦のフロー図 | 機種を **STD**(アテンション・入口) / **MID**(ステップアップ) / **FLAG**(ゴール・着地)の3段に並べ、矢印で「お客様の希望」ごとの流れを示します。3段とは限らず、使う段だけで構成できます。段を飛ばす流れは破線で表示します。 |
| 機種カード | 重要度の順に「メーカー＝型番 ＞ 価格(税込) ＞ 特徴 ＞ この機種で伝えること」を表示します。機種ごとに写真を添付できます。 |
| コンサルトーク | 矢印の番号に対応して、「ステップアップのヒアリング(STD→MID)」と「コンサルのしかた」を1ページ目に載せます。 |
| 今週の狙い／注意点・共有事項 | ページ上部に大きな文字で表示し、最優先で目に入るようにします。 |
| 付帯品／S4 | コンサルトークの下に、左「付帯品」・右「S4」の枠を表示します。注力することを1行1項目の箇条書きで入力します。見出しは書き換えできます。 |
| 詳細設定 | 項目ごとの文字サイズ(大・中・小)、段ごとの色(プリセット3種)、用紙(A4／A3)、向き(自動／横／縦)を選べます。 |
| PDF出力 | プレビューの見た目のまま、複数ページのPDFにして保存できます。 |

---

## 2. 使い方

1. **開く**: 公開URLをブラウザで開きます。画面は「作成」と「プレビュー」を切り替えます。
2. **基本情報**: タイトル、対象日、店舗、作成者、今週の狙いを入力します。
3. **機種を追加**: 「＋ STDを追加」「＋ MIDを追加」「＋ FLAGを追加」で機種を足し、メーカー・型番・価格・特徴・伝えること・写真を入力します。↑↓で順番を変えられ、「削除」で消せます。
4. **コンサルの流れを追加**: 「＋ 流れを追加」で、どの機種からどの機種へ進めるかを選び、ラベル(例「ゲームする」)、ヒアリング、コンサルのしかたを入力します。番号は自動で振られ、矢印とコンサルトークに同じ番号が出ます。
5. **注意点・付帯品・S4**: それぞれの欄に入力します。付帯品とS4は1行に1項目です。
6. **詳細設定**(必要なときだけ): 文字サイズ、色、用紙を調整します。「すべて初期値に戻す」でいつでも戻せます。
7. **確認**: 「プレビュー」で仕上がりを見ます(A4の見た目で表示されます)。
8. **保存**: 「保存」を押すと、このブラウザに作戦表が残ります。新しい週は「新規」、練習用には「サンプル」を使います。
9. **PDF出力**: 「PDFを出力」で保存します。店頭掲示や部下への配布に使います。

> **毎週の使い方の例:** 「サンプル」または前週の作戦表を開く → 機種と価格を更新 → 今週の狙いを書き換える → 保存 → PDF出力 → 朝礼で共有。

## 3. データの保存と安全性

> **結論:** 公開URLの版では、保存した作戦表はあなたのブラウザの中にだけ残り、外部のサーバーには送られません。GitHubやClaudeが中身を見ることはありません。

### 公開URL版(GitHub Pages)

- 保存先はそのパソコン・スマホのブラウザ(localStorage)です。写真もPDFも、ブラウザの中で処理されます。
- GitHubに置かれているのは **ツールのプログラム(`index.html`)だけ** です。URLを知っている人はツールを開けますが、あなたが保存した作戦表は見えません。
- アクセス解析や外部への送信は組み込んでいません。ただし起動時に、PDF作成用ライブラリとフォントを外部CDN(cdnjs・Google Fonts)から読み込みます。CDN側にアクセスの記録が残る可能性はありますが、作戦表の内容は送られません。
- リポジトリが公開設定の場合、プログラムと、最初から入っているサンプル内容(例のメーカー・型番)は誰でも見られます。

### Claude版(Artifact)

- 保存先はClaudeのサービス上の共有データベースです。公開前の状態では、閲覧できるのはあなたと、共有を許可した人だけです。共有範囲はページの「共有」メニューで管理します。

### 運用で気をつけること

| 項目 | 内容 |
|---|---|
| 端末ごとに別保存 | 公開URL版は、パソコンとスマホ、店長と部下で作戦表が共有されません。共有は **PDF** で行ってください。 |
| 共用パソコン | 同じブラウザを他の人が使うと、保存した作戦表が見えます。共用端末では使用後に削除するか、PDFだけ保存してください。 |
| データが消える場合 | ブラウザの履歴・サイトデータを消すと、保存した作戦表も消えます。大事なものはPDFで保管してください。 |
| 個人情報 | お客様の氏名・連絡先など、個人情報は書かないでください。 |
| 写真 | 機種写真は縮小して保存されます。メーカーの画像を使う場合は、利用条件を確認してください。 |

## 4. 公開と更新の方法(管理者向け)

公開は GitHub Pages(無料)で行っています。リポジトリ名は `sennryakumaker`、公開URLは https://hissernoob.github.io/sennryakumaker/ です。

### 更新の反映

```bash
cd ~/my-first-app
git add index.html && git commit -m "更新内容のメモ"
git push
```

反映には1〜2分かかります。

### Ver.1 に戻したいとき

```bash
git tag -f Ver.1                   # 現在の内容にVer.1の目印を付ける
git push -f origin Ver.1
git checkout Ver.1 -- index.html   # 後日、Ver.1の内容に戻す
```

### URL(リポジトリ名)を変える

GitHubの「Settings → Repository name」で変更します。古いURLは開けなくなるため、変更後は共有済みの方へ新しいURLを伝えてください。ユーザー名部分と `github.io` は無料では変えられません(独自ドメインは別途購入が必要です)。

## 5. 既知の制限

- 現在はテレビ(43型)の作戦づくりを前提にしています。他の商品カテゴリは今後の拡張です。
- PDFの出力は、写真入り・A3・縦向きの組み合わせでの実機確認がまだ十分ではありません。初回は出力結果を確認してから配布してください。
- 保存データは端末ごとで、自動の共有・同期はありません。
- 色は色彩検定の考え方(トーンの段階・アクセント色・コントラスト)を参考にした近似値で、正式なPCCS色番号ではありません。
